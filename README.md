# ✨ Overview

A premium AI-powered developer portfolio designed with modern UI/UX, smooth animations, and intelligent assistant integration.

The project combines a lightning-fast React frontend with a Flask backend to deliver a professional experience for recruiters, clients, and businesses.

Clone Repository

```bash

```

```bash

```

Run Frontend

```bash
npm run dev
```

Run Backend

```bash
cd backend

python main.py
```
